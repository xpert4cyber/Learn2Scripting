# ⚡ Why This Project Matters?

Most Windows systems are deployed with weak default logging.

That means attackers can:

❌ Run malware silently
❌ Abuse PowerShell undetected
❌ Move laterally through networks
❌ Dump credentials
❌ Deploy ransomware
❌ Create persistence
❌ Disable defenses
❌ Hide malicious activity

This project fixes that problem by enabling deep Windows telemetry automatically.
